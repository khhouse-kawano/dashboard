========================================================
 分析API（Claude Desktop 用）セットアップのご案内
========================================================

Claude Desktop から、注文事業のKPIや歩留まりを日本語で
質問できるようにするための設定です。

所要時間は5分程度です。


--------------------------------------------------------
 事前に用意するもの
--------------------------------------------------------

・APIキー
    「khg_kpi_」で始まる長い文字列です。
    開発者から別途お渡しします。

    ★ お手元に無い場合、または見当たらない場合は
      開発者にお問い合わせください。
      このキーが無いとセットアップは完了しません。

    ※ このキーはあなた専用です。他の方に渡さないでください。
    ※ メールやチャットに貼らないでください。
    ※ 紛失した場合も開発者にご連絡ください。
      同じキーの再確認はできないため、作り直しになります。


--------------------------------------------------------
 手順1  このフォルダを分かりやすい場所に置く
--------------------------------------------------------

zipを展開したフォルダを、消さない場所に置いてください。

    例）ドキュメント の中

※ 設定後にフォルダを消しても動きますが、
　 再設定のときに必要になります。


--------------------------------------------------------
 手順2  セットアップを実行する
--------------------------------------------------------

このフォルダの中にある

    セットアップ.cmd

を「ダブルクリック」してください。

黒い画面が開いて、処理が進みます。


▼「WindowsによってPCが保護されました」と出た場合

    1. 「詳細情報」をクリック
    2. 「実行」をクリック

    ダウンロードしたファイルに対する標準の確認画面です。


--------------------------------------------------------
 手順3  APIキーを入力する
--------------------------------------------------------

「APIキーの入力」という小さな画面が出ます。

    1. 白い枠の中をクリック
    2. Ctrl キーを押しながら V キー（貼り付け）
    3. OK をクリック

※ 入力した文字は ●●● と表示されます。
   確認したいときは「入力内容を表示する」に
   チェックを入れてください。


★ APIキーが手元に無い場合

    ここで「キャンセル」を押して中断してください。
    設定は変更されません。

    開発者にAPIキーを依頼し、受け取ってから
    手順2からやり直してください。

    ※ 推測で入力したり、他の方のキーを使ったりは
      しないでください。誰の操作かを記録している
      ため、他の方のキーを使うと利用状況が
      正しく残りません。


--------------------------------------------------------
 手順4  Claude Desktop の再起動
--------------------------------------------------------

「Claude Desktop を再起動します」と聞かれたら
「はい」を選んでください。

自動で終了して起動し直します。


--------------------------------------------------------
 手順5  動作を確認する
--------------------------------------------------------

Claude Desktop で、次のように聞いてみてください。

    分析APIで使える集計軸と指標を教えて

集計できる項目の一覧が返ってくれば成功です。


▼「どのディレクトリですか」と聞かれた場合

    設定が反映されていません。
    管理者にご連絡ください。


--------------------------------------------------------
 うまくいかないとき
--------------------------------------------------------

■「Node.js がインストールされていません」と出た

    管理者にご連絡ください。

■ セットアップ.cmd が開かない／すぐ閉じる

    次の方法をお試しください。

    1. このフォルダを開く
    2. 画面上部のアドレス欄（フォルダの場所が
       表示されている白い帯）をクリック
    3. 表示が反転したら powershell と入力して Enter
    4. 青い画面が開くので、次の1行を貼り付けて Enter

       powershell -ExecutionPolicy Bypass -File .\setup-windows.ps1

■ それでも解決しない

    黒い画面や、エラーの画面を
    スクリーンショットで管理者に送ってください。


--------------------------------------------------------
 使うときの注意
--------------------------------------------------------

・返ってくるのは集計された数値だけです。
  お客様の氏名・連絡先・住所は含まれません。

・重い集計を連続で実行すると、
  既存のダッシュボードが遅くなることがあります。
  まずは期間や条件を絞ってお試しください。

・「通電率」より「初回面談率」が高いなど、
  順序が逆転して見えることがあります。
  これは各フェーズの日付の入力率が異なるためで、
  データの誤りではありません。
