### ⚠️⚠️ 誰の実績にするか（attribution）

| | |
|---|---|
| ⚠️ 商談ログに `staff` がある | ⚠️ **その人** |
| ⚠️⚠️ **`staff` が空** | ⚠️ ⚠️ **顧客の現担当（`in_charge_user`）** |
| ⚠️ 顧客情報の列から拾ったぶん | ⚠️ 現担当 |

⚠️⚠️ **`staff` は18,470件中2,103件（11.4%）にしか入っていない。**
⚠️ ⚠️ **突合キーにするとほとんど拾えない**（⚠️ 実測: 商談顧客数 1,536 → 3,309）。

⚠️⚠️ **前任（`first_interviewed_user`）は使わない。**
⚠️ ⚠️ **列名は「初回面談の担当」ではなく、担当変更時に退避される前任者**
（⚠️ 以前のCRMのデータ構造をそのまま使っているための命名）。
⚠️ ⚠️ **併用すると、前任として名前が残っているだけで分母が増え、
⚠️ 引き継いだ人ほど率が下がる**（⚠️ 実測: 商談顧客数が 3,309 → 5,007）。

### ⚠️ 契約数を `status` にした理由

⚠️ 契約日の列で数えると ⚠️ **888件**、`status` だと ⚠️ **841件**。
⚠️ ⚠️ **差の47件は、契約日は入っているが `status` が `解約` などの顧客。**
⚠️⚠️ **顧客DBの実数に合わせる**という利用者の判断で `status` にした。

⚠️ ⚠️ **包含関係は保たれている**（実測）。

## ⚠️ 対象の絞り込み

```sql
SELECT s.name, s.shop, s.section
  FROM staff_list s
  JOIN shop_list sl ON sl.shop = s.shop
 WHERE s.period = ? AND s.report = 1 AND sl.division = ?
```

⚠️⚠️ **`shop_list.division` に「注文営業」という値は無い。**
⚠️ 実際の値は `注文事業` / `建売分譲事業` / `不動産企画室` / `中古リノベ`。
⚠️ ⚠️ **`注文事業` で絞っている。**

⚠️⚠️ **同じ人が複数ブランドに登録されている**（⚠️ 実測23名。最大3店舗）。
⚠️ ⚠️ **名寄せしないと、同じ実績がその人数ぶん重複して並ぶ。**
⚠️ 店舗欄は `/` でつないでいる。

⚠️ 結果: ⚠️ **staff_list 124行 → 96名。**

## ⚠️ 実装で踏んだこと

### ⚠️⚠️ `interview_log` は mysql2 が既にパース済みで返す

⚠️ 列の型は `longtext` だが、⚠️ **MariaDB が JSON として申告するため**。

```ts
// ⚠️⚠️ **`JSON.parse(String(v))` と書くと `"[object Object]"` になって全件壊れる。**
//   ⚠️ 実際に踏んだ（⚠️ 18,470行すべてが「解析できない」になった）。
const toLog = (value: unknown): LogEntry[] => {
  if (Array.isArray(value)) return value as LogEntry[];
  if (value !== null && typeof value === 'object') return [value as LogEntry];
  try {
    const parsed: unknown = JSON.parse(String(value ?? ''));
    return Array.isArray(parsed) ? (parsed as LogEntry[]) : [];
  } catch {
    return [];
  }
};
```

### ⚠️ 氏名の空白

⚠️⚠️ **台帳と商談ログで姓名の間の空白が割れている。**
⚠️ 実測: ⚠️ **ログ側131人のうち104人が空白入り**（`中川 康太`）、残りは空白なし。
⚠️ ⚠️ **落とさないと大半が突合できない。**

```ts
const norm = (value: unknown): string => String(value ?? '').replace(/[\s　]/g, '');
```

### ⚠️ action は完全一致

⚠️ ログには ⚠️ **`自社契約`(79) / `仲介契約`(10) / `売買契約`(25) / `リフォーム契約`(26)** や、
⚠️⚠️ **`自社契約,物件名(公開)` のように物件名が付いた値**もある。
⚠️ ⚠️ **指示どおり `契約` のみを対象にしている。**

const STAFF_CONTRACT_AUTHORITY = ['Master', 'BrandAdmin'];
