つなぐための手順

売り反響から媒介獲得台帳を作り、いえらぶに物件を登録し、ポータルから届く買い反響が台帳へ自動でつながるまでの流れと、気をつけることをまとめました。

1全体の流れ

媒介を取ってから、ポータルの問い合わせが台帳につながるまでは、次の順に進みます。白い枠が営業の作業で、灰色は Dashboard が自動で行います。

  1. ① 媒介紐付売り反響の画面で、媒介獲得台帳を作る
  2. ② いえらぶに登録台帳の所在地・建物名をコピーして貼り付ける
  3. ③ CSV を取り込むいえらぶの物件一覧を Dashboard に上げる
  4. ④ 台帳とつながる所在地・種別が同じ物件に自動でつながる
  5. ⑤ 買い反響がつながるSUUMO・HOME'S・アットホームの問い合わせが台帳へ

営業の作業自動

なぜ大事か

台帳といえらぶの物件がつながると、ポータルから届いた買い反響が「どの媒介物件への問い合わせか」まで自動で記録されます。物件ごとの反響数や、自社で客付けした割合を正しく数えるための土台です。

2媒介紐付（媒介を取ったとき）

媒介獲得台帳は、必ず売り反響から作ります。台帳の画面からは新しく作れません。どの反響から来た売主かを、あとで辿れるようにするためです。

  1. 左のメニューの売り反響（一括査定）を開き、該当の反響の行の右の方にある🔗 媒介紐付を押します。

  2. 売り反響の内容が入った状態で、登録の画面が開きます。* の付いた項目はすべて必須です。確かめて、足りないところを直します。

    • 媒介の種類：専属専任媒介／専任媒介／一般媒介
    • 媒介契約日：未来の日付は入れられません
    • 有効期間の満了日：最初は「契約日の3か月後の前日」が入ります。専属専任・専任は3か月を超えられません（宅建業法）
    • 売出価格・担当者・売主・物件の所在地・物件の種別
    • 種別がマンションのときは、建物名と部屋番号も入れてください（建物名は必須）
    ここで入れる所在地が、いえらぶとつなぐ「鍵」になります

    所在地は番地まで正確に入れてください（例：鹿児島市テスト町5丁目5-5）。番地が無い・途中までしか無いと、あとでいえらぶの物件と自動でつながりません。地図の URL が付いていても構いません（比べるときは無視します）。

  3. 登録を押すと、媒介獲得台帳に1行ができ、売り反響の段階が「媒介受託」になります。媒介獲得台帳で No.〇 を開くで、その台帳へ移れます。

    以前に同じ物件を媒介・買取していれば、「以前の台帳と同じ物件に紐づけました」と出ます。

3媒介獲得台帳で確かめる

左のメニューの媒介獲得台帳を開くと、作った台帳が並んでいます。いちばん右の「ポータル連携（いえらぶ）」の列が、いえらぶの物件とのつながりです。

札意味すること
No.274111いえらぶの物件番号につながっているなし
要確認 2件所在地が近い物件が見つかったが、1件に決められない札を押して、候補から選んで保存（6章）
いえらぶ未採番所在地が同じ物件が、いえらぶにまだ無いいえらぶに登録して、CSV を取り込む（4章・5章）
該当なしいえらぶに載せない物件にしたなし

一覧の上の⑥ いえらぶで、「要確認」「いえらぶ未採番」の台帳だけに絞れます。件数も出ます。

ついでに確かめること

同じ一覧の「REINZ」の列にレインズ登録の期限（専属専任は5営業日・専任は7営業日）、「販売報告」の列に次の販売報告の期限（専属専任は7日・専任は14日ごと）が出ます。期限が近いと黄色、過ぎると赤です。

4いえらぶに登録するときの決まり

Dashboard は、台帳といえらぶの物件を所在地と種別（マンションは建物名・部屋番号も）で突き合わせて、自動でつなぎます。表記が1文字でもずれると自動でつながらず、手で直す手間が増えます。

いちばん大事な決まり

いえらぶに物件を登録するときは、所在地と建物名を、Dashboard の台帳から「コピー」して「貼り付け」てください（Ctrl+C → Ctrl+V）。手で打ち直さないでください。

  1. 媒介獲得台帳で、その台帳の札（または行の編集）を押して、編集画面を開きます。

  2. 番地の欄の下にある所在地をコピーを押します。マンションなら建物名をコピーも使います。

  3. いえらぶ cloud の物件の登録画面で、所在地の欄に貼り付けます（Ctrl+V）。建物名も同じように貼り付けます。

いえらぶの登録で気をつけること

  • 担当店舗は「国分ハウジンググループ中古住宅専門店」にしてください。Dashboard は、この店舗の物件だけを台帳と突き合わせます。
  • 物件種別は、台帳の種別に合うものを選んでください（下の表）。合わないと「要確認」になります。
  • 所在地には番地まで入れ、建物名・部屋番号は所在地に混ぜず、それぞれの欄に入れてください。
  • マンションは部屋番号も入れてください。同じ建物の別の部屋と区別するためです。
  • 同じ住所に区画が2つある土地（A区画・B区画など）は、自動では決められず「要確認」になります。台帳の画面で候補から選んでください。
台帳の種別いえらぶの物件種別
戸建中古一戸建て（新築一戸建て）
マンション中古マンション
住宅用地売地
賃収マンションマンション（建物全部）・アパート
賃収・事業用アパート・ビル（建物全部）・マンション（建物全部）・売地
つながらない例台帳「鹿児島市テスト町5丁目5-5」／いえらぶ「鹿児島市テスト町5丁目5」（番地が途中まで）

5いえらぶの物件を Dashboard に取り込む

2026年11月から

いえらぶのログインに2段階認証（メール）が必要になり、以前のような毎日の自動の取り込みができなくなりました。いえらぶに物件を登録・更新したら、次の手順で取り込んでください。

  1. いえらぶ cloud の売買物件一覧を、店舗ごとに開きます。

  2. 一覧をダウンロード → CSV形式でダウンロードで、ファイル（sale_日付.csv）を保存します。

  3. Dashboard の左のメニューの設定・データ管理を開き、「いえらぶの物件一覧を取り込む（CSV）」でファイルを選びます。店舗ごとの複数のファイルを、まとめて選べます。

    件数（新しい物件・更新・価格の変更）が出るので、確かめて取り込むを押します。

  4. 「取り込みました」と出れば終わりです。同時に台帳との突き合わせも動き、新しくつながった台帳・買い反響の件数が出ます。

  • ファイルは、いえらぶからダウンロードしたまま選んでください。Excel で開いて保存し直すと、物件番号の形が崩れることがあります。
  • 同じ物件は上書きします。CSV に無い項目は、今の値のまま残ります。価格が変わったときは、価格の履歴に残ります。
  • いえらぶから無くなった物件は消しません。
  • カードの上に「今の件数」と「最後に取り込んだ日」が出ます。日付が古いままなら、取り込みを忘れていないか確かめてください。
係で決めておくこと

だれが・いつ取り込むか（物件を登録した日ごと、毎朝など）を、係の中で決めてください。取り込まないと、台帳は「いえらぶ未採番」のまま、買い反響も台帳につながりません。

6つながり方を確かめる・直す

取り込んだあと、媒介獲得台帳の「ポータル連携（いえらぶ）」の列を見ます。

「要確認」のとき

  1. 「要確認 N件」の札を押すと、編集画面に所在地が近いいえらぶの物件の候補が出ます。正しい物件を押します。

  2. 画面の下の保存するを押します。保存すると、その物件番号の過去の買い反響も台帳につながります。

自動でつながった台帳

編集画面の「掲載物件連携（いえらぶの物件）」に「自動で連携」と物件番号が出ます。違う物件につながっていたら、外すを押してから正しい物件を探して選び、保存してください。

  • 欄には物件番号・物件名・所在地の一部を入れて探せます（例：274111、西伊敷 50-3）。
  • いえらぶに載せない物件は該当なし（いえらぶに載せない）を押して保存します。以後、自動でつながりません。
  • 人が選んだ・外した・該当なしにした台帳は、自動の突き合わせで変えられません。
すぐにつなぎたいとき

突き合わせは30分ごとと、台帳を保存したとき、CSV を取り込んだときに動きます。媒介獲得台帳の一覧の上のいえらぶと突き合わせを押すと、その場で動きます。

7買い反響と台帳のつながり

SUUMO・HOME'S・アットホームから届いた買い反響は、問い合わせの物件番号（いえらぶの物件番号と同じ）から、その物件の媒介獲得台帳に自動で紐づきます。台帳がいえらぶの物件とつながっていることが条件です。

メールで届いた反響や、電話・来店の反響は自動ではつながりません。買い反響の編集画面の「問合せ物件（媒介獲得台帳）」で、台帳No.・売主名・所在地の一部・いえらぶの物件番号を入れて探し、候補を押して保存してください。

  • 紐づけると、買い反響の一覧の「問合せ物件」に「📝No.〇」の札が出ます。
  • 媒介終了の台帳は候補に出ません。

8そのほか共有しておくこと

「いえらぶ未採番」がいつまでも消えません
いえらぶに登録したあと、CSV を取り込んだか確かめてください（5章）。取り込んでも消えないときは、いえらぶの所在地・種別・担当店舗が台帳と合っているかを見て、合っていなければ台帳の編集画面で物件番号を探して選んでください。
違う物件につながってしまいました
台帳の編集画面で外すを押し、正しい物件を選んで保存します。外した台帳は、自動で別の物件につながりません。
媒介が終わった物件をもう一度媒介しました
売り反響から、いつもどおり媒介紐付をしてください。同じ所在地なら「以前の台帳と同じ物件」に紐づき、台帳の一覧に「同じ物件の台帳 N件」と出ます。いえらぶの物件も、新しい台帳につながります。
出稿前に売れた物件は、いえらぶに登録しなくてよいですか
いえらぶに載せないなら、台帳の編集画面で該当なしにして保存してください。「いえらぶ未採番」のまま残らず、一覧で見分けやすくなります。
台帳の所在地を直したら、いえらぶも直す必要がありますか
はい。台帳の所在地を直したら、いえらぶの所在地も、台帳からコピーして貼り付け直してください。ずれたままだと、次の物件の突き合わせで迷う原因になります。
担当者の欄の書き方は
反響・台帳・商談案件とも、空白なしの氏名にそろえています。選択肢から選べば、そのまま入ります。
困ったとき

Dashboard の右上の業務ガイドで「反響から商談案件へのつながり」「設定（不動産企画係）」を開くと、同じ内容をいつでも確かめられます。画面がおかしいとき・取り込みで止まるときは、システムの担当者に、画面のスクリーンショットを添えて連絡してください。
