# デプロイ手順 v2.2.279　月・期の選択肢を新しい順に／販促媒体別反響推移（注文）に「期間を反転」

| # | 何が変わるか | どこ |
|---|---|---|
| 1 | 月・期を選ぶ欄の選択肢が、新しい月・期が上に来る順になる。販促媒体別反響推移（注文）の表が、今月を左に並べる（「期間を反転」で古い月から） | ① フロント（Dashboard） |
| 2 | 更新履歴・業務ガイド1本（反響推移） | ① DB `backend/scripts/sql/2026-11-18_update_log_2.2.279.sql` |

- ① PHP・② VPS の変更はありません。表の変更もありません。
- ⚠️ v2.2.278 までのデプロイを先に済ませてください（このブランチは v2.2.278 の上に作っています）。

## 順序
```
0. v2.2.278 までのデプロイが終わっていること
1. GitHub で v2.2.279 を production へマージ（PR）
2. ① Dashboard のフロント（npm run build → アップロード）
3. ① SQL：2026-11-18_update_log_2.2.279.sql   ← ⚠️ 1回だけ
```

### 手順2　【① フロント】
いつもどおり `npm run build` してアップロードします。画面左上の版が 2.2.279 になればよいです。

### 手順3　【① SQL】
phpMyAdmin で `2026-11-18_update_log_2.2.279.sql` を **1回だけ**流します（更新履歴1行＋業務ガイド1本）。
```sql
SELECT no, version, date FROM update_log ORDER BY no DESC LIMIT 2;
SELECT title, updated_at FROM guide_article WHERE title = '反響推移（販促媒体別・店舗別）';
```

## 終わったら（動作確認）
- 反響一覧・顧客DB・反響MAP・販促媒体別広告費・店舗別広告費・反響推移・店舗・担当別反響・全社報告用フォーマット・予算詳細で、月・期の選択肢の一番上が今月（今の期）になっている。
- 店舗・担当別反響は、選択肢が「〇年5月期」（新しい順）→ 月（新しい順）の順で、開いたときは今月が選ばれている。
- 販促媒体別反響推移（注文）の表が「全期間」の右に今月から並び、「期間を反転」で古い月からに変わる。
