## 2. push → PR マージ

### 【あなたのPC（PowerShell）で実行】


### ⚠️⚠️ `git push origin HEAD:production` は使わない

⚠️ PR のマージで `production` にマージコミットが付くため、ローカルのブランチは
`production` の子孫にならない。⚠️ **構造的に必ず reject される。**

1. `git push origin v2.2.137`

3. PR をマージする
