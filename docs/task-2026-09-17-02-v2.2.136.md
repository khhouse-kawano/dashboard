⚠️⚠️ **ボタン表記をそのまま置き換えると矛盾する。**

## ⚠️ 3つの軸と、既存の3関数の対応

⚠️⚠️ **新しい計算ロジックは書いていない。** ⚠️ 指示の3パターンが、既にある3関数とちょうど1対1で対応していた。

| axis | ボタン表記 | 編集できる | disabled | 使う関数 | 動くもの |
|---|---|---|---|---|---|
| `total`（⚠️ **新規**） | **広告費総額を修正** | 広告費総額 | 歩留まり・KPI単価 | `applyBudget` | ⚠️ 4つの件数が比例（単価は保つ） |
| `unit` | **反響数を修正** | 歩留まり（件数） | 広告費総額・KPI単価 | `applyCountKeepUnit` | ⚠️ 広告費とほかの件数が比例 |
| `budget` | **KPI単価を修正** | KPI単価 | 広告費総額・歩留まり | `applyUnit` | ⚠️ その件数 ＝ 広告費 ÷ 単価 |

⚠️⚠️ **キー名と編集できる欄は一致していない**（`'budget'` で編集するのは単価）。
⚠️ キーは 2026-09-14 からのもので、⚠️ **変えると過去のドキュメントと突き合わせられなくなる**ため残した。

## `budgetSimulatorUtils.ts`

### ⚠️ `SimAxis` の差し替え（全文）

```ts
/**
 * 試算の軸。
 *
 * ─────────────────────────────────────────────
 * ⚠️⚠️ **2026-09-17 に「軸＝どの欄を書き換えるか」へ変わった**（指示）。
 *   ⚠️ 以前は「何を固定するか」で、**全部の欄が常に編集できた。**
 *     そのため「いま何を動かしているのか」が画面から読めなかった。
 *   ⚠️ 現在は ⚠️ **軸ごとに1種類の欄だけが編集でき、残りは disabled** である。
 *
 * ⚠️⚠️ **3つの軸は、下の3つの関数と1対1で対応している。**
 *
 *   'total'  … **広告費総額**だけを書き換える（⚠️ `applyBudget`）
 *       ⚠️ 単価を保ったまま4つの件数が比例して動く。
 *       ⚠️ **「この予算ならどこまで取れるか」**を見るときの軸。
 *       disabled … 歩留まり（件数）・KPI単価
 *
 *   'unit'   … **歩留まり（件数）**だけを書き換える（⚠️ `applyCountKeepUnit`）
 *       ⚠️ 単価を保つため**広告費が動く**。ほかの3つの件数も同じ比率で動く。
 *         契約を1.5倍にするなら反響も来場も1.5倍要る、という意味である。
 *       ⚠️ **「この件数を取るにはいくら要るか」**を見るときの軸。
 *       disabled … 広告費総額・KPI単価
 *
 *   'budget' … **KPI単価**だけを書き換える（⚠️ `applyUnit`）
 *       ⚠️ 広告費を保ったまま `件数 = 広告費 ÷ 単価` になる。
 *       ⚠️ **「単価がここまで下がったら何件取れるか」**を見るときの軸。
 *       disabled … 広告費総額・歩留まり（件数）
 *
 * ⚠️⚠️ **キー名と編集できる欄は一致していない**（'budget' で編集するのは単価）。
 *   ⚠️ キーは 2026-09-14 からのもので、**保存された試算は無いが
 *     名前を変えると過去のドキュメントと突き合わせられなくなる**ため残してある。
 *   ⚠️ **画面に出す名前は `AXIS_LABEL` を見ること。**
 * ─────────────────────────────────────────────
 */
export type SimAxis = 'budget' | 'unit' | 'total';

/** 入力欄の種類。⚠️ 表の3つの欄に対応する */
export type SimField = 'budget' | 'count' | 'unit';

/**
 * ⚠️⚠️ **その軸で編集できる欄。ここが唯一の定義である。**
 *   ⚠️ 画面側で `axis === 'unit'` のような条件を書かないこと。
 *     以前は3か所に散っていて、軸を1つ足すたびに**どれかが漏れた。**
 */
export const EDITABLE_FIELD: Record<SimAxis, SimField> = {
    total: 'budget',
    unit: 'count',
    budget: 'unit',
};

/** その軸でその欄を編集できるか */
export const canEdit = (axis: SimAxis, field: SimField): boolean =>
    EDITABLE_FIELD[axis] === field;

/**
 * 軸を選ぶボタンの表記。
 *
 * ⚠️⚠️ **「〜を固定」ではなく「〜を修正」**（2026-09-17 の指示）。
 *   ⚠️ **編集できる欄の名前**を出すこと。固定される側の名前を出すと、
 *     押したあとに**その欄が disabled になって矛盾する。**
 */
export const AXIS_LABEL: Record<SimAxis, { label: string; hint: string }> = {
    total: {
        label: '広告費総額を修正',
        hint: 'この予算で達成できる件数を見る',
    },
    unit: {
        label: '反響数を修正',
        hint: '目標の件数から必要な広告費を出す',
    },
    budget: {
        label: 'KPI単価を修正',
        hint: '単価が変わったときの件数を見る',
    },
};

/** ⚠️ ボタンの並び順。⚠️ 「予算 → 件数 → 単価」と、考える順に並べる */
export const AXIS_ORDER: SimAxis[] = ['total', 'unit', 'budget'];
```

### ⚠️ `applyCount()` にコメントを足しただけ（本体は無変更）

⚠️⚠️ **画面から呼ばれなくなったが、消していない**（勝手に削除しない方針）。

```ts
/**
 * 件数を変えたとき。
 *
 * ⚠️ **広告費は固定**。単価は導出なので自動で変わる
 *   （「総反響を 20 にしたら反響単価が 1/2 になる」）。
 *
 * ⚠️⚠️ **2026-09-17 以降、画面からは呼ばれていない。**
 *   ⚠️ 件数を編集できるのは `'unit'` の軸だけになり、そこでは
 *     `applyCountKeepUnit()`（単価を保つ側）を使うため。
 *   ⚠️ **消していない。** 「広告費を固定したまま件数だけ動かす」は
 *     軸を足すときに再び要る可能性がある。
 */
export const applyCount = (row: SimRow, kpi: KpiKey, nextCount: number): SimRow => ({
    ...row,
    counts: { ...row.counts, [kpi]: Math.max(0, Math.round(nextCount)) },
});
```

```tsx
/**
 * 入力欄の見た目。
 *
 * ⚠️⚠️ **編集できない欄は「入力できない値」に見えること**（2026-09-17 の指示）。
 *   ⚠️ `disabled` を付けるだけでは、ブラウザによっては**ほとんど色が変わらない。**
 *     ⚠️ 背景・文字色・枠線を自前で落とし、**カーソルも not-allowed** にする。
 *   ⚠️ ⚠️ **値そのものは消さない。** 消すと昨年実績（試算の出発点）が読めなくなる。
 */
const inputStyle = (editable: boolean): React.CSSProperties => ({
    fontSize: '12px',
    textAlign: 'right',
    ...(editable ? {} : {
        backgroundColor: '#eef1f5',
        color: '#8a949f',
        borderColor: '#dde3ea',
        cursor: 'not-allowed',
        // ⚠️ 文字を薄くするだけだと「読み込み中」に見えるので、枠も一緒に落とす
        opacity: 1,

/**

 * ⚠️ 色を落とすだけでは**壊れているように見える。** 理由を一言で出す。

    <span className="ms-1 text-secondary" style={{ fontSize: '10px' }}>
        <i className="fa-solid fa-lock me-1" aria-hidden="true" />固定
    </span>
);
```
