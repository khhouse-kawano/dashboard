### 手順1　【② VPS】backend-express を更新
```bash
cd ~/dashboard
git fetch --depth 1 origin production
git checkout FETCH_HEAD
```
```bash
dcp build express-api
```
```bash
dcp up -d express-api
```
確認（トークンなし。② に直接）:
```bash
curl -s -X POST https://api.khg-marketing.info/api/gateway -H 'Content-Type: application/json' -d '{"request":"planner","roll":"settings"}'
```
- `認証が必要です。`（401）ならよいです。
- ② が起動していることは、起動ログで確かめます（`--tail` は付けない）：
```bash
dcp logs express-api | grep "planner:settings" | tail -1
```
- 先頭の時刻が、今 `up -d` した時刻（UTC）ならよいです。

### 手順3　【① SQL】
phpMyAdmin で `2026-11-05_update_log_2.2.249.sql` を **1回だけ**流します。

## 注意
- レインズ登録日・直近報告日が入っていない台帳は、期限が過ぎていると赤で出ます。登録・報告が済んでいれば、台帳の編集画面で日付を入れると消えます
- 契約満了の「期限間近」は、今までの「30日前から」から「**14日前から**」に変わります（仕様書）。一般媒介にも出るようになります
