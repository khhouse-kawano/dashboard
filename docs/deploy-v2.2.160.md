## ⚠️ 順序

```
1. ② VPS（Express の再ビルド）   ← ⚠️⚠️ 先に出すこと
2. ① フロント（build）
3. ① SQL（update_log）
```

⚠️⚠️ **2 を先に出すと、選択は出るのに課・店舗が空のままになります**
（⚠️ 選択肢は ② が返しているため）。⚠️ 表そのものは従来どおり出ます。
