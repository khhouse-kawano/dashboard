# 2026-10-15 資金計画書で金利データ.js が反映されない不具合の修正（v2.2.191）

## 依頼
- `frontend/build/funding-plan/index.html` の金利を、新しい `金利データ.js`（Downloads/ReadMeClaud、2026-10-15・33商品）で更新したい
- 案A（① の `/dashboard/funding-plan/` に `金利データ.js` を置く）を実行したが反映されない
- 方針: **保存済みの計画書でも常に新しい金利でよい**（2026-10-15 の指示）

## 調査結果
- ① から `https://khg-marketing.info/dashboard/funding-plan/金利データ.js` は **200・2026-10-15 の内容で配信されていた**（ファイル側は問題なし）
- 33商品の id は計画書の `LOANS` と全件一致
- 原因は計画書側の順番:
  1. ファイル末尾で `bootLoad()`（② から顧客の計画書を取る。**非同期**）を呼ぶ
  2. 直後に `applyFeed(window.KHG_RATE_FEED)` で S.loans に新しい金利を入れる
  3. 1 の応答が後から返り、`bootLoad` 内の `S = base;` で **DEF() の金利＋保存済みの loans に戻る**
  - 画面には「✅ 金利データ.js から 33件 読み込みました」と出るため、反映されたように見える
  - 連携版（localStorage → ② の DB）にしたときに入った問題。単独版は顧客の読み込みが同期だったので起きなかった

## 変更ファイル
| ディレクトリ | ファイル | 内容 |
|---|---|---|
| frontend/public/funding-plan | **index.html** | 関数 `bootLoad` の `S = base;` の直後で `applyFeed` を当て直す |

（関数の追加なし。① の `金利データ.js` はそのまま使う。リポジトリには入れていない）

## 修正（bootLoad の該当部分）
```js
    S = base;

    /* ⚠️⚠️ 金利データ.js をここで当て直す（v2.2.191）。
         起動時（ファイル末尾）にも applyFeed しているが、bootLoad は通信なので**後から終わり**、
         上の `S = base` で DEF() の金利・保存済みの loans に戻ってしまう（2026-10-15 に発覚）。
       ⚠️ 保存済みの計画書でも**常に最新の金利**にする（2026-10-15 の指示）。
         変わるのは⑨の商品一覧（S.loans）だけ。②の d_rate など選んだ金利は動かない。
       ⚠️ 下の mark(false) より前に置くこと（開いただけで「未保存」扱いにしない）。 */
    if(window.KHG_RATE_FEED) applyFeed(window.KHG_RATE_FEED, "金利データ.js");

    reloadAll();
    mark(false);
    refreshList();
```

## 確認（Playwright。② の応答は偽物、金利データ.js は Downloads の実物）
保存済みの計画書の loans に古い金利 9.999 を入れて開いた。

| 版 | 保存済み（kagin） | 未作成（kagin） | 基準日 | 未保存扱い |
|---|---|---|---|---|
| 修正前 | **9.999（古いまま）** | 1.6 | **2026-08-20** | なし |
| 修正後 | **1.6** | 1.6 | **2026-10-15** | なし |

- `S.loans` を使うのは ⑨ 銀行金利比較の中だけ（一覧・比較・書出・一括反映）。② デジシキで選んだ金利（d_rate）や保存済みの計算結果は変わらない
- 保存し直すと、その時点の金利が計画書の loans に入る
