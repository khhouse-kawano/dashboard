## ⚠️ 期間の判定

### ⚠️⚠️ 日付の形式がそろっていない

⚠️ 実測（2026-10-01）:

| 出所 | 例 | 件数 |
|---|---|---|
| `interview_log.day` | `2026-02-28` | 24,534 |
| 〃 | `2026/06/01` | 113 |
| ⚠️ 〃 | ⚠️⚠️ **`202604-04-05`** | 2 |
| ⚠️ 〃 | ⚠️⚠️ **`【買】契約完了日`** | 1 |
| 初回面談の列 | `2025/08/16` | 3,654 |
| 〃 | `2025-08-04` | 2,739 |
| ⚠️ 〃 | ⚠️⚠️ **`262026-04-26`** | 1 |

```ts
/**
 * 日付から `YYYY-MM` を取り出す。読めなければ空文字。
 *
 * ⚠️ ⚠️ **読めない値は空文字を返し、期間指定時は対象から外す。**
 *   ⚠️ 弾かずに無理やり解釈すると、⚠️ **別の月に混ざる。**
 */
const toMonth = (value: unknown): string => {
  const matched = /^(\d{4})[-/](\d{1,2})(?:[-/]|$)/.exec(String(value ?? '').trim());
  if (matched === null) return '';
  return `${matched[1]}-${matched[2].padStart(2, '0')}`;
};
```

### ⚠️⚠️ 期間なしのときは日付を見ない

```ts
const inRange = (month: string, range: MonthRange): boolean => {
  if (range.start === '' && range.end === '') return true;
  if (month === '') return false;
  ...
};
```

⚠️ ⚠️ **指定なしのときに日付の無い顧客を落とすと、
何も選んでいないのに件数が減る。**

### ⚠️ 何の日付で見るか

| KPI | 見る日付 |
|---|---|
| 商談顧客数 | ⚠️ 商談ログの `day`（⚠️ **その記録1件の日付**）／ 顧客情報の4列 |
| 次アポ数 | ⚠️ 第二面談・事前審査・契約の日付 |
| ⚠️ **契約数** | ⚠️⚠️ **契約日の列** |

⚠️⚠️ **商談顧客数は記録単位で判定している**（⚠️ 顧客単位ではない）。
⚠️ ⚠️ **顧客単位にすると、期間外の初回面談しか無い人まで入る。**

⚠️⚠️ **契約数だけ扱いが違う。**
⚠️ `status` には日付が無いため、⚠️ **期間を見るには契約日の列を使うしかない。**
⚠️ ⚠️ **契約済みなのに契約日が空の顧客は、期間を指定すると落ちる。**
⚠️ ⚠️ **指定なしのときは `status` だけで数える**ので、⚠️ **全期間の合計は顧客DBの実数と一致する（841件）。**

## ⚠️ 選択肢の並び順

⚠️ サーバーが ⚠️ **マスタの順のまま**返す。

| | 並び |
|---|---|
| 課 | ⚠️ `section_list` の `no` 順（⚠️ 注文事業は no=1〜7） |
| 店舗 | ⚠️ `shop_list` の `id` 順（⚠️ 49件） |

⚠️⚠️ **画面側で並べ直さないこと。** ⚠️ マスタの意図した順が崩れる。
⚠️ ⚠️ **`orderByMaster()` と同じ考え方**（⚠️ あちらは文字列の配列をマスタ順に並べ替える関数で、
⚠️ ここでは**最初からマスタ順で返している**ため呼ぶ必要が無い）。

⚠️ 店舗は ⚠️ **`show_flag` で絞っていない。**
⚠️ ⚠️ **絞ると、選択肢から消えた店舗に属する営業の行が出せなくなる。**

## ⚠️ 複数の課・店舗に属する営業

⚠️⚠️ **1人が複数に属していることがある**（⚠️ 行では `/` でつないである）。
⚠️ ⚠️ **完全一致では落ちる**ので、`/` で割ってから突き合わせる。

```ts
const match = (value: string, target: string) =>
    target === '' || value.split('/').map(v => v.trim()).includes(target);
```

⚠️ 実測:

| | 人数 |
|---|---|
| ⚠️ **複数の課に属する営業** | ⚠️ **4名**（中脇 優介・脇田 晃司・森吉 大樹・瀬戸 成那） |
| ⚠️ 複数の店舗に属する営業 | ⚠️ **23名** |

⚠️⚠️ **そのため「課ごとの合計」は全体と一致しない**（⚠️ 4名が2回数えられる）。
⚠️ 実測: ⚠️ 課ごとの商談の合計 **3,651** / 全体 **3,478**（⚠️ 差 173 ＝ 重複分）。
⚠️ ⚠️ **誤りではない。** ⚠️ 絞り込みはあくまで「その課を含む営業」を出すもの。
