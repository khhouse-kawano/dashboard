## 1. 共通ルール
### トリガーの原則
1. トリガーは「**ステータスを変えて保存した瞬間**」に1回だけ動く。画面を開いた・項目を入れただけでは動かない
2. 前提条件を満たさなければ**保存させない**。足りない項目の名前を画面に出す。ステータスだけ先に変わって自動処理が動かない状態を作らない
3. 自動処理は、トリガーの保存と**同じトランザクション**で行う。途中で失敗したら全部戻す（作成先だけできる・元のステータスだけ変わる、を防ぐ）
4. 自動で作ったレコードは、保存後にそのレコードへ移るか、**リンクを出す**

### 連動の方向
| 種類 | 内容 |
|---|---|
| 作成の連動 | 元のステータス変更で、先を新しく作る（一方向） |
| 紐づけ | 元と先の両方に相手の ID を持たせ、どちらからも開ける（双方向） |
| 状態の連動 | 先の結果（成約・失注など）を元に反映する。組み合わせは各フェーズで決める |
| 引継ぎ | 作った時点の値を写す。あとで元を直しても先には反映しない（例外は各フェーズ） |

### 二重作成の防止
- 元がすでに先と紐づいていれば、もう1つは作らず、既存のレコードへ案内する
- ステータスを戻してから再びトリガーのステータスにしても、紐づけが残っていれば作らない
- 例外：③の自社客付け（売・買の2件）のように、仕様で複数を作ると決めたもの

### 取消・差戻し
- 自動で作ったレコードは**物理削除しない**。「取消」にし、元との紐づけは履歴に残す
- 元のステータスを戻せるのは、先が「取消」のときだけ。進行中の先があれば、戻せないと表示する
- 取消・差戻しは**理由が必須**

### 監査ログ
- トリガーで動いた作成・更新・紐づけは、すべて記録する（日時・操作者・元・先・変更前後の値）

### 権限
- トリガーになるステータスの変更：そのレコードの担当者と管理者（課長）
- 担当者按分（③）の変更、取消・差戻し、消費税の確定値の修正（⑤）：管理者だけ
- 月次締め後（翌月以降）の、その月のデータの変更：管理者だけ

## 2. ① 売り反響 → 媒介獲得
- **トリガー**：売り反響のステータスを「媒介獲得」（＝今の「媒介受託」）にして保存したとき
- **前提条件**（満たさなければ保存しない）

| 項目 | 条件 | 備考 |
|---|---|---|
| 媒介の種類 | 専属専任・専任・一般のどれか | 必須 |
| 媒介契約日 | 日付。未来の日付は不可 | 必須 |
| 有効期間の満了日 | 専属専任・専任は契約日から3か月以内でなければエラー。一般は3か月を超えると警告（保存はできる） | 必須。初期値は「契約日の3か月後の前日」。⚠️ 3か月の上限は宅建業法の定め |
| 売出価格 | 1円以上の整数 | 必須 |
| 担当者 | 担当者マスタから選ぶ | 必須。初期値は売り反響の担当者 |
| 物件の所在地 | 入力済み | 必須（②の物件を作るのに使う） |
| 物件の種別 | 戸建・マンション・土地・その他 | 必須 |
| 一般媒介の他社 | 一般のときだけ。明示型なら他の依頼先の業者名 | 任意 |

- **自動処理**
  1. 売り反響を「媒介獲得」にし、媒介獲得日を媒介契約日にする
  2. ②（台帳と媒介物件の作成・紐づけ）を同じ保存の中で行う
  3. 媒介獲得件数を、媒介契約日の月・担当者に1件数える
  4. 朝礼アラート「直近14日の新規媒介獲得」に載せる（14日で外す）
  5. 売り反響を、架電キュー・追客の対象から外す
- **例外**
  - 同じ売主・物件の売り反響が複数ある：1件を媒介獲得にし、残りは「重複」で閉じて同じ台帳に紐づける（件数は1件）
  - 自社で買い取る：①ではなく④
  - 媒介獲得のあとに自社買取へ切り替えた：④の例外（買取転換）
  - 契約の直後に解除された：台帳を「取消」にし、売り反響を戻す。件数からも外す
- 要確認（課長）：媒介獲得件数を数える日付を、契約日にするか登録日にするか（仕様書は契約日で書いている）

## 3. ② 媒介獲得 → 台帳・媒介物件（連動。独立した操作は無い）
- **台帳を作る経路は①だけ**。紹介・直接の依頼も、反響元「紹介」「直接」で売り反響を作ってから①を行う
- **自動処理**
  1. 媒介物件を探す（所在地（地番）と種別。マンションは建物名と部屋番号も）
  2. 一致すれば紐づけ、無ければ新しく作る（過去の媒介・買取の履歴を1つの物件にまとめる）
  3. 台帳を作り、台帳番号を振る
  4. 引き継ぐ項目を写す
     - 売り反響から：売主名・連絡先・反響元・反響日・査定額・担当者
     - ①の入力から：媒介の種類・契約日・満了日・売出価格
     - 媒介物件から：所在地・種別・土地面積・建物面積・築年・間取り。台帳では参照表示にする
  5. 台帳の現況を「販売準備中」にし、売出開始日を入れたら「販売中」にする
  6. 売り反響・台帳・媒介物件の三者を、双方向に紐づける
  7. 期限を計算して、期限アラートの対象にする
- **期限**

| 期限 | 専属専任 | 専任 | 一般 |
|---|---|---|---|
| レインズ登録 | 契約日の翌日から5営業日以内 | 契約日の翌日から7営業日以内 | 対象外 |
| 初回の販売報告 | 契約日から7日 | 契約日から14日 | 対象外 |
| 有効期間の満了 | 満了日の14日前から警告 | 同左 | 同左 |

  - 2回目以降の販売報告の期限は、「送付済」で保存した報告日から計算し直す
  - 営業日の計算には、会社の休業日カレンダーが要る（置き場所は情報システム部が決める）
- **台帳の現況**
  - 販売準備中（②で作ったとき）
  - 販売中（売出開始日を入れたとき）
  - 買付有（③で申込を受けたとき。自動）
  - 契約済（商談案件が契約済になったとき。自動）
  - 成約（商談案件が決済済になったとき。自動）
  - 終了（期間満了・解約・他社で成約・買取転換。理由が必須）
- **例外**
  - 更新：同じ台帳で期間を更新し、前の期間は履歴に残す（件数に数えない）
  - 種類の変更：同じ台帳で種類を変え、変えた日から期限を計算し直す（履歴に残す）
  - 満了後に再び媒介：新しい売り反響から①を行い、新しい台帳を作る（媒介物件は既存に紐づく）
  - 売出価格の変更：変更前の価格と変更日を履歴に残す

## 4. ③ 買い反響 → 申込獲得 → 商談案件（担当者按分）
| パターン | 物件 | 買主 | 作る案件 | トリガーの場所 |
|---|---|---|---|---|
| ③-A 自社客付け | 自社の台帳物件 | 自社の買い反響 | 売側と買側の2件 | 買い反響 |
| ③-B 他社客付け | 自社の台帳物件 | 他社が案内した買主 | 売側の1件 | 台帳（「申込受付（他社客付け）」を保存） |
| ③-C 他社物件 | 他社が元付けの物件 | 自社の買い反響 | 買側の1件 | 買い反響 |

- **トリガー**：③-A・③-C は、買い反響を「申込獲得」（＝今の「購入申込」）にして保存したとき。③-B は、台帳で「申込受付（他社客付け）」を保存したとき
  - 台帳の現況を「買付有」に変えただけでは、案件を作らない
- **前提条件**
  - 全パターンで必須：申込日（未来の日付は不可）、申込価格（1円以上）、担当者と按分割合（合計100％）
  - 対象物件：③-A・③-B は台帳から選ぶ。③-C は所在地と元付の業者名を入れる
  - 買主：③-A・③-C は買い反響から選ぶ。③-B は買主名と客付の業者名を入れる
  - 決済予定日・ローンの有無は任意（契約までに入れる）
- **自動処理**
  1. 案件を作り、取引番号を1つ振る（③-A の2件は同じ取引番号）
  2. 仲介手数料の初期値を申込価格から計算する（売買価格×3％＋6万円＋消費税。400万円を超える場合の上限額）。合意した額に直せるようにする
  3. 台帳物件なら、台帳の現況を「買付有」にし、台帳と案件を紐づける
  4. 買い反響と買側の案件を紐づける
  5. 朝礼アラート「直近14日の商談リスト登録」に載せる（14日で外す）
- **担当者按分**
  - 初期値：売側の案件は台帳の担当者、買側の案件は買い反響の担当者を100％にする
  - 共同担当は案件ごとに別に設定する
  - 割合は整数の％で、合計が100％でなければ保存しない
  - 計上額は、仲介手数料（税抜）×割合。リフォーム粗利も同じ割合で分ける
  - 端数は、担当者ごとに1円未満を切り捨て、合計との差は主担当（先頭）に寄せる
  - **計上月は決済日の月**
  - 作成のときは作成者が設定できる。あとで変えられるのは管理者だけ（監査ログに残す）。締め後も同じ
- **状態の連動**

| 案件の変化 | 台帳 | 買い反響 |
|---|---|---|
| 契約済 | 契約済 | 契約 |
| 決済済 | 成約 | 成約 |
| 失注（申込の撤回など） | ほかに進行中の申込が無ければ「販売中」に戻す | 「追客中」に戻すか「失注」にするかを選ばせる |

  - ③-A では、片方を失注にしたとき、同じ取引番号のもう片方も失注にするかを確かめて、一緒に処理できるようにする
- **例外**
  - 同じ台帳物件に2番手以降の申込：申込ごとに案件を作り、番手を持たせる。1番手が失注したら、2番手を繰り上げるか確かめる
  - 選んだ買い反響に進行中の案件がある：「既に案件あり（取引番号）」と出し、確かめてから作れる
  - 失注済みの買い反響から再び申込：既定では候補に出さず、切り替えて選べる。選んだら「申込獲得」に戻す
  - 案件と台帳の紐づけを解除：買側の案件と買い反響の紐づけも外すかを確かめる

## 5. ④ 売り反響 → 買取獲得 → 買取案件
- **トリガー**：売り反響のステータスを「買取獲得」にして保存したとき（売主と買取の売買契約を結んだ時点）。⚠️ 今の売り反響には、この段階が無い
- **前提条件**
  - 買取契約日（未来の日付は不可）
  - 買取価格（総額。1円以上）
  - 引渡し（決済）の予定日
  - 売主の区分：個人／課税事業者（インボイス登録あり）／免税事業者・登録なしの事業者
  - 物件の現況：空家／売主が居住中／賃貸中
  - 物件の所在地・種別
  - 担当者
  - 仕入の内訳（土地・建物）：概算でよく、決済時に確定する
- **自動処理**
  1. ②と同じ方法で物件を探して紐づけるか、新しく作る
  2. 買取案件を作って番号を振る（ステータスは「取得前」）
  3. 売り反響・買取案件・物件を双方向に紐づける
  4. 買取獲得件数を、買取契約日の月・担当者に1件数える
  5. 売り反響を、架電キュー・追客の対象から外す
  6. ⑤を概算で計算し、今期の消費税の見込みに「取得前（概算）」として入れる
- **買取案件のステータス**

| ステータス | 変わるきっかけ | 自動で動くこと |
|---|---|---|
| 取得前 | ④の保存 | なし |
| 在庫 | 取得の決済日を入れて保存 | 取得日を確定し、在庫日数と期限アラートを始める。⑤の仕入側を確定値にする |
| 販売中 | 再販の売出開始日を入れたとき | 買い反響の問合せ物件として選べるようにする |
| 再販契約済 | 再販の売買契約を保存したとき | ⑤の販売側を確定値で計算する |
| 売却済 | 再販の決済日を入れて保存 | 粗利を確定し、決済月の売上に入れる |

- **期限アラート**
  - 長期在庫：取得日から180日
  - 取得後2年
  - 第3年度の末日：取得日を含む課税期間を第1年度として、第3年度の課税期間（5月末）の末日。居住用賃貸建物の調整に関係する
- **例外**
  - 買取転換：台帳を「終了（買取転換）」にし、売り反響を「買取獲得」にして④を行う（買取案件は既存の物件に紐づく）
  - 業者から紹介された：反響元「業者紹介」で売り反響を作ってから④を行う
  - 買取契約が解除された：買取案件を「取消」にし、売り反響を戻す（消費税の見込みからも外す）
  - 取得前に決済予定日が延びた：予定日を直し、課税期間をまたぐなら見込みの期を移す
- 要確認（課長・経理）
  - 買取転換のとき、もとの媒介獲得件数を取り消すか残すか（仕様書は残す前提）
  - 再販の買主を自社の買い反響から付けたときの売上の計上（仲介手数料は出ない）

## 6. ⑤ 買取案件の仕入内訳（土地・建物）と消費税
- 土地は非課税、建物は課税。仕入と販売のそれぞれで、総額を土地と建物に分ける
- ⚠️ **税の扱いは、実装の前に経理と顧問税理士の確認を受ける**。システムは計算と根拠の記録を担い、申告額を決めるものではない
- **計算のトリガー**

| きっかけ | 計算すること | 値の状態 |
|---|---|---|
| ④の保存 | 仕入側の按分と仕入税額 | 概算 |
| 内訳・按分の方法・費用を追加・変更して保存 | その項目と案件の収支 | 変更前と同じ |
| 取得の決済日を保存 | 仕入側を確定値にし、課税期間を取得日で決める | 仕入確定 |
| 再販の売買契約を保存 | 販売側の按分と売上の消費税 | 販売確定 |
| 再販の決済日を保存 | 売上の課税期間を引渡し日で決める | 販売確定 |
| 経理が決算を確定 | 当期分の消費税の項目を固める | ロック |

- **按分の方法**（根拠の書類が必須。方法と根拠が無ければ「仕入確定」「販売確定」にできない）
  - 契約書の内訳（売買契約書）
  - 固定資産税評価額の比（固定資産評価証明書）
  - その他の合理的な方法（鑑定書など。理由のメモが必須）
- **固定資産税評価額の比で分けるとき**
  - 建物価額 ＝ 総額 × 建物評価額 ÷（土地評価額＋建物評価額）。1円未満は切り捨て
  - 土地価額 ＝ 総額 − 建物価額
  - 建物価額は、消費税込みの金額として扱う
  - 固定資産税等の精算金も、同じ比率で分けて購入代金に含める
- **仕入税額**
  - 建物価額（税込）× 10/110。1円未満は切り捨て
  - 売主がインボイス登録ありなら、登録番号を持つ
  - 売主が個人・登録なしなら、宅建業者の特例で帳簿の保存だけで控除できる見込み（帳簿に売主の住所を書いたかを持つ）
- **居住用賃貸建物**
  - 現況が「賃貸中」で、建物価額の税抜が1,000万円以上ならフラグを立て、経理の確認を必須にする
  - フラグが立ったら、仕入税額を「控除不可（確認中）」にして見込みから外す
  - 第3年度の末日までに再販したら、加算見込み額（控除不可額 × 経理が入れる割合）を出す
- **付随費用の税区分の初期値**（経理が費目マスタで変えられる。個別対応方式）

| 費目 | 税区分 | 用途の区分 |
|---|---|---|
| 建物購入代金 | 課税 | 課税売上対応（居住用賃貸建物は控除不可） |
| 土地購入代金 | 非課税 | － |
| 固定資産税等の精算金 | 建物分は課税・土地分は非課税 | 建物分は課税売上対応 |
| 仕入時の仲介手数料 | 課税 | 共通対応（土地建物比で分けるのも可。経理が判断） |
| 司法書士報酬 | 課税 | 共通対応 |
| リフォーム工事費 | 課税 | 課税売上対応（外構・造成など土地の工事は要確認） |
| 解体・測量費 | 課税 | 案件ごとに選ぶ（土地として売るなら非課税売上対応） |
| 再販の広告費・他社への仲介手数料 | 課税 | 共通対応 |
| 登録免許税・不動産取得税・印紙税 | 対象外 | － |
| 借入利息・保証料 | 非課税 | － |

- **販売時**
  - 再販価格を、仕入と同じ方法の中から選んで分ける
  - 売上の消費税 ＝ 建物価額（税込）× 10/110（切り捨て）
  - 土地は非課税売上として、金額を持たせる
  - 方法ごとの税額を比べる画面があると役立つ（ただし、採用する方法には根拠の添付が必須）
- **案件ごとの収支**
  - 控除できる仕入税額 ＝ 課税売上対応分 ＋ 共通対応分 × 課税売上割合
  - 案件の納付見込み ＝ 売上の消費税 − 控除できる仕入税額
  - 課税売上割合と計算方式（初期値は個別対応方式）は、経理が期ごとに設定する（営業は入れない）
- **今期の納付見込み**
  - 課税期間は6/1〜翌5/31
  - 期は、仕入は取得日、売上は引渡し日、費用は完了・引渡しの日で決める
  - 「確定値」と「概算・取得前」を分けて出す
  - 画面に「買取再販部門の見込みであり、会社の申告額ではない」と書く
- **計算例（テスト用）**
  - 仕入 20,000,000円、評価額は土地 6,000,000円／建物 4,000,000円
  - 建物 8,000,000円、仕入税額 727,272円
  - 再販 29,800,000円（うち建物 9,000,000円）、売上の税額 818,181円
  - 差引 90,909円
- 要確認（経理・顧問税理士）
  - 個人から仕入れた建物の帳簿保存の要件
  - 居住用賃貸建物の判定と、第3年度の調整の計算
  - 仕入時の仲介手数料の用途区分
  - 課税売上割合に、前期実績と今期見込みのどちらを使うか
