## ⚠️ 変更内容（全文）

### `frontend/src/components/header/StaffContractRate.tsx`

⚠️ 変更前:

```css
                .sc_wrap { font-size: 13px; color: #1f2937; }
```

⚠️ 変更後:

```css
                /**
                   ⚠️ 2026-10-02（v2.2.162）: ⚠️⚠️ **全画面にしたら端まで詰まって読みづらくなった。**
                     ⚠️ 左右と下に余白を取る。
                   ⚠️⚠️ **固定値にしないこと。** ⚠️ 狭い画面で左右48pxも空けると、
                     ⚠️ 16列ある表の見える幅がそのぶん削られる。
                     ⚠️ ⚠️ **clamp で画面幅に追従させている**（16px 〜 48px）。
                   ⚠️ 上は少なめ。⚠️ モーダルの見出しのすぐ下なので、空けすぎると間延びする。 */
                .sc_wrap { font-size: 13px; color: #1f2937;
                           padding: 4px clamp(16px, 3vw, 48px) 28px; }
```

### ⚠️ なぜ `p-5`（Bootstrap のクラス）にしなかったか

⚠️ 依頼は「⚠️ **p-5等で**」であり、⚠️ 余白が付けば手段は問わないと解釈した。

| | ⚠️ `p-5` を付けた場合 | ⚠️⚠️ **採用した clamp** |
|---|---|---|
| 広い画面 | 左右 48px | ⚠️ 左右 48px（⚠️ **同じ**） |
| ⚠️⚠️ **狭い画面** | ⚠️⚠️ **左右 48px のまま** | ⚠️ **16px まで詰まる** |
| 上の余白 | 48px（⚠️ 間延びする） | ⚠️ 4px |

⚠️⚠️ **この表は16列ある。**
⚠️ ⚠️ **狭い画面で左右に48px固定で取ると、見える列がそのぶん減る。**
⚠️ 上の48pxも、⚠️ モーダルの見出しのすぐ下なので空きすぎる。

⚠️ また、⚠️⚠️ **このコンポーネントは共通CSSを使わず自前のスコープCSSで作ってある**
（⚠️ ファイル冒頭のコメント「共通CSSを汚さない」）。⚠️ そちらの作法に合わせた。
