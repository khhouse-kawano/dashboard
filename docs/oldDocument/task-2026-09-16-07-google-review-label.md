## 変更点

| 箇所 | 変更前 | 変更後 |
|---|---|---|
| テーブル先頭行の見出し | `口コミ数` | **`レビュー数`**（幅 90px → 100px） |
| KPIカード | `口コミ総数` | `レビュー総数` |
| 平均評価の補足 | `（口コミ数で加重）` | `（レビュー数で加重）` |
| 見出し横の注記 | `※ 評価・口コミ数は…` | `※ 評価・レビュー数は…` |
| テーブルの上 | — | ⚠️ **注意書きを新設** |

⚠️ 見出しの幅を 90px → 100px にしたのは、「レビュー数」が1文字長く、⚠️ **並べ替えアイコンと重なって折り返す**ため。

## 追加した CSS クラス

`.gr_caution`（`GoogleReview.tsx` 内の `<style>`）

⚠️ 既存の `.gr_note` は **11px の一行注記**で、今回の長文を入れると読めない。⚠️ 別クラスにした。
⚠️ `flex-shrink: 0` を付けている。⚠️ **外すと表が伸びたときにここが潰れる**（`.gr_wrap` が flex のため）。

## 注意書きの文面

> レビュー数は Dashboard が取り込んだ時点の数です。「ユーザー自身が過去の自分の口コミを削除した」、「Google のスパムフィルターやポリシー違反（虚偽の投稿、不適切なコンテンツなど）の判定により、Google 側が口コミを削除した」等のケースでレビュー数が減ることもあります。

⚠️ **書かないと「取り込みが壊れている」と受け取られる**ため、表の直前に置いた。
