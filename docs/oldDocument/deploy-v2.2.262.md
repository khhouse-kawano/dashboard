## 順序
```
0. GitHub で v2.2.262 を production へマージ（PR）
1. ① Dashboard のフロント（v2.2.262 のブランチで npm run build）
2. ① SQL：2026-11-10_update_log_2.2.262.sql      ← ⚠️ 1回だけ
```

### 手順1　【① フロント】
- いつもどおり `npm run build` して、`build/` の中身を上げます。
- ⚠️ 今回 `build/static/js/` に手順書だけの小さな js（`*.chunk.js`）が1つ増え、`build/static/media/` に手順書の画像（`01_leadsell.*.png` など12枚）が増えます。**`build/` の中身を丸ごと**上げてください（一部だけ上げると、手順書を開いたときに「読み込み中…」のまま、または画像が出ません）。

### 手順2　【① SQL】
phpMyAdmin で `2026-11-10_update_log_2.2.262.sql` を **1回だけ**流します。
```sql
SELECT no, version, date FROM update_log ORDER BY no DESC LIMIT 2;
SELECT id, title, sort FROM guide_article WHERE sort IN (199, 265);
```
- update_log の一番上が 2.2.262 で、1行だけならよいです。
- 記事が2本（集客サマリー・媒介・いえらぶ手順書（不動産企画係））出ればよいです。

## 終わったら（動作確認）
1. 「集客イベント → 集客サマリー」で総予算の金額を押す
   - 上に請求先ごとの合計が出る
   - 表の列が「期間・店舗・請求先・詳細・金額」（「イベント」の表示が無い）
2. 事業を「不動産企画係」にして、左のメニューの「点検・管理」→「媒介・いえらぶ手順書」
   - 手順書が開き、写真が出る
   - 目次を押すと、その章へ移る
   - 「印刷する」で、手順書だけが印刷の画面に出る
3. Dashboard の版の表示が ver2.2.262

## 切り戻し
- フロントを前の版に戻すと、v2.2.261 の明細（媒体・請求先を1列）に戻り、手順書のメニューも消えます。
- 記事は残りますが、害はありません（消すなら `UPDATE guide_article SET published = 0 WHERE title = '媒介・いえらぶ手順書（不動産企画係）';`）。
