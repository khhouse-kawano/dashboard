## LINE WORKS の調査（エージェント、2026-10-12）
- `https://line.worksmobile.com/message/send?emailList=` は **公式文書に無い**。実際は `talk.worksmobile.com/join?emailList=…` へ転送される。`emailList` は **LINE WORKS のアカウント（ログインID）** 用と見られ、お客様の個人 LINE ID では相手にならない
- LINE WORKS から **個人 LINE ID でお客様を検索・追加する手段は無い**。外部トークは「社員が QR / 招待リンクを送り、お客様が LINE で友だち追加」の流れのみ（管理者の許可が必要）
  - https://help.worksmobile.com/ja/message/message-guide/message-with-external-user/message-line-user/
  - https://help.worksmobile.com/ja/use-guides/contacts/external-contacts/line-user/
- Bot / API の送信先は LINE WORKS メンバーのみ（一般 LINE ユーザーへは送れない見込み）
  - https://developers.worksmobile.com/jp/docs/bot-user-message-send
- 一般 LINE の `line.me/R/ti/p/…` は公式アカウント向け・PC 版 LINE は非対応
- → **アイコンは「LINE ID をコピー ＋ LINE WORKS のトーク（https://talk.worksmobile.com/）を開く」にした**（LineWorksButton.tsx の LINE_WORKS_TALK_URL を変えれば開き先を変えられる）
