  - 前後の確認の SELECT と、戻すときの SQL（コメント）が入っている

## 追記：本番で ERROR 1175（安全更新モード）
- 本番で流したところ、`UPDATE` が「safe update mode」で止まった（`ERROR 1175`）。止まったのは UPDATE だけで、データは変わっていない
  - 本番の前の確認：佐賀店の注記がある 104／kh 106件
  - 控えの表は、この1回目で、直す前の値のまま作られている
- 直したこと：UPDATE の条件に主キー `id > 0` を足した（安全更新モードのままでも通る。モードは切らない）
- ローカルで、安全更新モード（`SET SQL_SAFE_UPDATES = 1`）を入れて流し直し、エラー無しで 102件とも消えることを確かめた
- 本番では、直した SQL をもう一度、頭から流してよい
  - 控えの表は `CREATE TABLE IF NOT EXISTS` なので作り直されず、1回目の値（直す前）のまま残る
