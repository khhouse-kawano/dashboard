## ① 行のまとめ方

```
総反響 / SUUMO / HOME'S / アットホーム / 公式LINE / ホームページ反響
```

⚠️ まとめ行は**末尾**。⚠️ 先頭に置くと内訳に見えて誤読される。

⚠️⚠️ **「総反響から show_graph=1 を引く」形にはしていない。**
⚠️ 引き算だと、媒体が空・`medium_kaeru` に無い値の反響が**黙ってまとめ行に入る**。
⚠️ 足し算なら**表に出ない＝気づける**。

⚠️⚠️ **`Number()` を通すこと。** DB から `"0"` / `"1"` の文字列で来ることがあり、
⚠️ `=== 1` の厳密比較だと**全部 false になって行が消える**。

⚠️ `show_graph` 列がまだ無い環境では**全媒体がまとめ行に入る**（2行になる）。⚠️ 例外にはならない。

## ② `budget.section = 'spec'`

⚠️ **元から効いていた**（`BUDGET_SECTION.spec`）。⚠️ 変更していない。

## ③ 販促費を担当店舗に限る

⚠️ 列名は `in_charge_shop` ではなく ⚠️ **`in_charge_store`**。

⚠️⚠️ **`NOT IN` ではなく `IN` で書くこと。**
⚠️ `in_charge_store` に NULL と空文字が混ざっており、⚠️ `NOT IN` だと**1行も返らない**（検証中に踏んだ）。
