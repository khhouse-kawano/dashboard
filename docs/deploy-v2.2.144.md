⚠️ 中身: ⚠️ **SatBaseサマリー（物件台帳 1,910件）を追加。**
⚠️ ⚠️ **広告出稿状況 / Instagram投稿状況を画面のトグルで更新できるようにした。**

| # | 何が変わるか | どこ |
|---|---|---|
| 1 | ⚠️⚠️ **`satbase_property` テーブルを新設**（42列・1,910行） | ⚠️ **① DB** |
| 2 | ⚠️ **`satbase_list` / `satbase_update` の2リクエスト**を追加 | ⚠️ **② Express** |
| 3 | 転送リストに2件追加（⚠️ **2か所とも**） | ① PHP |
| 4 | ⚠️ 土地・物件管理 → ⚠️ **土地情報同期・土地情報一覧を削除**、⚠️ **SatBaseサマリーを追加** | ① フロント |
| 5 | 更新履歴に1行増える | ① DB |

⚠️⚠️ **v2.2.143 を先に通しておくこと。**

⚠️ ⚠️ **① に PHP ハンドラは無い（Express 専用）。**
⚠️ ⚠️ **② が古いままだと 502 になる。** ⚠️ **順序を必ず守ること。**

---

## ⚠️ 順序

```
1. ① SQL（⚠️ テーブル作成 → データ → update_log）
2. ② Express の再ビルド
3. ① PHP（express_proxy.php）
4. ① フロント
```

⚠️⚠️ **1 → 2 → 3 → 4 の順を守ること。**

| 間違えると | 何が起きるか |
|---|---|
| ⚠️ テーブルを作らずに 2 | ⚠️ **画面を開いた瞬間に 500 → ① が 502 を返す** |
| ⚠️ ② より先に 3・4 | ⚠️ **「ループ検知」で 502**（⚠️ **① に PHP が無いのでフォールバックもできない**） |

## 手順2　【② VPS で実行】Express の再ビルド

```bash
cd ~/dashboard
git fetch --depth 1 origin production
git checkout FETCH_HEAD
ls backend-express/src/features/satbase.ts
dcp build express-api
dcp up -d --force-recreate express-api
```

⚠️⚠️ **`git pull` は使わないこと**（この環境は detached HEAD が正しい）。

⚠️ 反映の確認は ⚠️ **起動ログ**で行う。

```bash
dcp logs express-api | grep "satbase"
```
