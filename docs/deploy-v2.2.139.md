## ⚠️ 手順5　② VPS で Express を再ビルドする

### 【② VPS で実行】

```bash
cd ~/dashboard
git fetch --depth 1 origin production
git checkout FETCH_HEAD
```

⚠️⚠️ **`git fetch --depth 1` はコミットが1つしか来ない（`grafted`）。**
⚠️ ⚠️ **`git log` で取り込みを確認しないこと。** ⚠️ **ファイルの中身を見る。**

```bash
grep -c "header_blacklist_edit" backend-express/src/gateway/registry.ts
ls -l backend-express/src/features/blacklist.ts
```

⚠️ 前者が ⚠️ **1以上**、後者が ⚠️ **存在すること。**

```bash
dcp build express-api
dcp up -d express-api
dcp ps
```

⚠️⚠️ **`dcp` は alias である。**

```
docker compose -f ~/dashboard/docker-compose.prod.yml --env-file ~/dashboard/.env.prod
```

⚠️ ⚠️ **素の `docker compose` は `.env.prod` を読まない。** ⚠️ **必ず `dcp` を使うこと。**

### ⚠️ 疎通の確認（② で実行）

```bash
curl -s -o /dev/null -w "%{http_code}\n" -X POST http://localhost:3001/api/gateway \
  -H "Content-Type: application/json" -d '{"request":"header_blacklist_edit"}'
```

⚠️⚠️ **`401` が返れば登録されている。**
⚠️ ⚠️ **`404` なら未登録**（⚠️ ビルドが古い。⚠️ `dcp build` からやり直す）。
