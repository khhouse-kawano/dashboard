コードからの使用箇所なし（推定：国分ハウジング不動産 本店の顧客を、不動産の顧客管理システムから書き出して取り込んだ写し。媒体に「かえるHP」「SUUMO」などがあり、建売・中古の買い／売りの反響が混ざる）。
1行＝1顧客（の1案件）。登録日の最大は 2026-04 ごろで、それ以後は更新されていない（推定）。
⚠️ 画面・処理からは使っていない（推定）。開発用の個人情報マスク（mask_personal_info.sql）の対象には入っている。

## 列
- no: 連番（自動採番）
- id_action: （推定）元システムの顧客（追客）ID
- staff: 担当者
- shop: 店舗（ほぼ「株式会社　国分ハウジング不動産　本店」）
- id_related: （推定）元システムの関連ID
- name: 顧客名
- kana: 顧客名のかな
- estate_name_1: （推定）問い合わせた物件名
- category: （推定）希望の種別など。JSON 配列の文字列（多くは空文字の配列）
- medium: 反響媒体（かえるHP(会員登録） / SUUMO / アットホーム など）
- case: 案件の区分（「買:」「売:」＋物件種別）
- id_case: （推定）元システムの案件ID
- status: 追客の状態（追客中 / 接触（通話・返信） / 来店あり / 契約 / 追客終了 など）
- mail: メールアドレス
- zip: 郵便番号
- address: 住所
- phone: 電話番号
- registered: 登録日時
- reserved: （推定）来店予約日
- contract: （推定）契約日・契約番号（形がそろっていない）
- action: 対応履歴（date・method などを持つ JSON 配列の文字列）
- rank: ランク（S / C / D / E / F）
